# Personal Portfolio Website

## Description
A full-stack portfolio website developed using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

## Features
- Responsive Design
- Skills Section
- Projects Section
- Contact Form
- Backend Integration

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB

## How to Run

### Frontend
Open index.html in browser.

### Backend
1. Open terminal
2. Run npm install
3. Run npm start
